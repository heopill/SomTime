# 섬타임 (SomTime) — 구현용 디자인 명세

> 앱 이름: 한국어 **섬타임**, 영어 **SomTime** (다이나믹 아일랜드의 "섬" + 시계의 "타임").
> `design/mockups/` 폴더의 HTML 파일은 목업 원본입니다. 브라우저로 여는 용도가 아니라, 색상·크기·간격 값을 읽기 위한 참고 자료예요. 값이 이 문서와 다르면 **이 문서를 우선**합니다.

## 1. 앱 개요

전체 화면으로 영상을 볼 때도 상단을 내리지 않고 시간을 확인할 수 있게, 다이나믹 아일랜드(Live Activity)와 PiP 플로팅 창에 시계를 띄우는 iOS 앱.

화면 구성:

| 화면 | 목업 파일 | 역할 |
|---|---|---|
| 홈 | `Main.dc.html` | 아일랜드 시계 토글, PiP 시계 토글, 서버 시간 메뉴, 설정 요약 |
| 설정 | `Settings.dc.html` | 시계 디자인(가로 슬라이드), 색상, 시간 형식, 초 표시 |
| 서버 시간 | `ServerTime.dc.html` | 사이트 주소 입력 → 서버 시각 측정 → 표시 방식 선택 → 시작 |
| Live Activity 표시 상태 | `IslandStates.dc.html` | 세로 Compact, 가로, Minimal, Expanded, 잠금 화면, PiP |
| 가로 전체 화면 (Live Activity) | `Landscape.dc.html` | 가로 영상 위 아일랜드 시계 |
| 가로 전체 화면 (PiP) | `PipLandscape.dc.html` | 가로 영상 위 PiP 시계 창 |
| 컴포넌트 | `Components.dc.html` | 재사용 컴포넌트 12종과 상태 |

목업의 화면 크기는 390×844pt(iPhone 기준)이고, 상단 56pt 여백은 상태 표시줄 자리입니다. 실제 구현에서는 Safe Area를 따르세요.

## 2. 핵심 기술 결정

### Live Activity (다이나믹 아일랜드)
- ActivityKit Live Activity 하나로 구현. compact leading/trailing, minimal, expanded, 잠금 화면 뷰를 모두 정의해야 함.
- **iOS 27부터** 가로 모드에서도 다이나믹 아일랜드에 Live Activity가 표시됨. 가로에서는 폭이 늘어나지 않으므로 `isDynamicIslandLimitedInWidth` 환경 값(WWDC26 발표 기준 이름, Xcode 27 문서에서 확인 필요)으로 분기해 가로 레이아웃을 그림.
- 가로/세로용 Live Activity를 따로 만들 수 없음. **하나의 뷰 코드 안에서 조건 분기**.
- Live Activity는 약 **8시간** 후 시스템이 종료함(잠금 화면엔 최대 4시간 더 남음). 홈에 남은 시간 표시, 종료 시 재시작 안내 필요.
- Live Activity는 앱이 매초 업데이트하는 구조가 아님. 시스템이 자동 갱신하는 텍스트를 사용:
  - 세로 한 줄 표기: `Text(timerInterval: 자정...다음자정, countsDown: false)` 트릭으로 `HH:mm:ss` 표시 가능. 자정에 구간 갱신 필요. 24시간제만 가능.
  - 12시간제, 시·분·초를 따로 나눠 그리기(가로 모드)는 iOS 18+의 현재 시각 표시 API(`TimeDataSource` / `.currentDate` 계열)로 가능한지 **먼저 검증**할 것. 불가능하면 가로 모드도 한 덩어리 텍스트로 대체.
  - 타이머 텍스트는 실제보다 넓은 폭을 차지하는 경향이 있으니 `.frame(width:)`로 고정.
- 다이나믹 아일랜드가 없는 기기(iPad, 노치 iPhone, SE): Live Activity는 잠금 화면에만 표시. 이 기기들에서는 PiP를 주 기능으로 보여줄 것. 다이나믹 아일랜드 유무를 알려주는 공식 API는 없으므로 기기 모델 또는 상단 Safe Area 높이로 판별.

### PiP 플로팅 시계
- `AVPictureInPictureController` + `AVSampleBufferDisplayLayer`로 시계 화면을 영상 프레임처럼 렌더링.
- 일반 PiP 시계: `HH:mm:ss`, **밀리초 없음**, 1초 단위 갱신.
- 서버 시간 PiP: 사용자가 켜면 밀리초까지 표시(30~60fps 렌더링, 배터리 소모 주의).
- PiP는 동시에 하나만 가능.

### 서버 시간
- 입력한 URL에 `HEAD` 요청(막히면 `GET`) → 응답 `Date` 헤더로 서버 시각 획득.
- `Date` 헤더는 초 단위이므로, 짧은 간격으로 반복 요청해 **초가 바뀌는 순간**을 잡아 오차를 수십 ms 수준으로 줄임. 네트워크 지연은 왕복 시간의 절반으로 보정.
- 결과는 "폰 시각 대비 오프셋"으로 저장하고, 표시할 때 `폰 시각 + 오프셋` 사용.
- Live Activity에 적용할 때는 타이머 구간을 오프셋만큼 이동.
- 측정은 앱이 포그라운드일 때만. "다시 맞추기" 버튼 제공.
- CDN을 쓰는 사이트는 실제 서버와 시각이 다를 수 있음(사용자 안내 문구 고려).

### 앱 이름과 App Store
- 지역별 이름 현지화: 한국 스토어 **섬타임: 아일랜드 시계**, 그 외 **SomTime: Island Clock**.
- 홈 화면 표시 이름(`CFBundleDisplayName`)도 현지화: 한국어 `섬타임`, 영어 `SomTime`. `InfoPlist.xcstrings`(String Catalog)로 관리.
- 영어 표기는 T를 대문자로 쓴 `SomTime`으로 통일(일반 단어 sometime과 구분).
- "Dynamic Island"는 Apple 상표. 앱 이름에 직접 쓰지 말고, 부제/설명에서 "Clock for Dynamic Island"처럼 설명형으로만 사용. 설명란 끝에 상표 고지 추가.

### Xcode 프로젝트 구성
- 앱 타깃: SwiftUI, Storage **None**(설정값은 `@AppStorage`/`UserDefaults`로 충분).
- Widget Extension 타깃 추가, **Include Live Activity** 체크. Live Activity UI는 이 확장에 위치.
- App Groups capability를 앱과 위젯 확장 양쪽에 추가하고, 시계 디자인·색상·형식·서버 시간 오프셋은 App Group의 `UserDefaults(suiteName:)`로 공유.
- 앱 Info.plist에 `NSSupportsLiveActivities = YES`.
- PiP: Background Modes에서 **Audio, AirPlay, and Picture in Picture** 체크, `AVAudioSession` 카테고리 `.playback` 설정.
- 커스텀 폰트를 쓰면 앱과 위젯 확장 양쪽 번들에 포함.
- 테스트: 처음엔 없어도 되지만, 서버 시간 오프셋 계산과 `Date` 헤더 파싱은 나중에 Swift Testing 타깃을 추가해 단위 테스트할 것을 권장.

## 5. 화면별 명세

### 홈
1. 헤더: 작은 영문 라벨 "SomTime" + 타이틀 "섬타임", 오른쪽 설정 아이콘 버튼.
2. 미리보기 영역(높이 210, 검정): 아일랜드 모양 미리보기. 꺼짐 폭 126 → 켜짐 폭 220으로 애니메이션. PiP가 켜지면 오른쪽 아래에 작은 PiP 창 미리보기. 아래 상태 문구("다이나믹 아일랜드에 표시 중" 등).
3. 기능 카드: 다이나믹 아일랜드 시계(토글) → 상태 문구 "켜짐 · 약 7시간 59분 후 자동 종료" / "세로 · 가로 모두 표시 (iOS 27+)".
4. 기능 카드: PiP 플로팅 시계(토글) → "켜짐 · 영상 위 작은 창으로 표시 중" / "영상 위에 떠 있는 작은 창".
5. 메뉴 행: 서버 시간 → 서버 시간 화면으로 이동.
6. 하단: 설정 요약 행 → 설정 화면.

### 설정
1. 헤더: 뒤로 버튼 + "설정".
2. 아일랜드 미리보기(높이 96): 선택한 디자인·색상·형식이 실시간 반영.
3. 시계 디자인: 디자인 카드 가로 슬라이드(화면 끝까지 이어지고 다음 카드가 살짝 보임).
4. 색상: 스와치 6개, 섹션 제목에 선택한 색 이름 표시.
5. 표시 옵션 그룹: 시간 형식(24시간/12시간 세그먼트), 초 표시(토글).
   - 일반 PiP의 밀리초 옵션은 **없음**. 밀리초는 서버 시간 화면에서만.

### 서버 시간
1. 헤더: 뒤로 버튼 + "서버 시간".
2. 사이트 주소: 입력창 + "측정"(측정 후 "다시 맞추기").
3. 결과 카드(검정): "{호스트} 서버 시간", 서버 시각 38pt, "내 폰보다 0.42초 빠름 · 오차 ±0.03초". 측정 전에는 안내 문구.
4. 표시 방식: 선택 버튼 2개(다이나믹 아일랜드 / PiP 플로팅 시계).
5. PiP 선택 시에만: "밀리초 표시" 토글(설명: 티켓팅처럼 정확한 순간이 필요할 때). 켜면 결과 카드에도 밀리초 표시.
6. 하단 기본 버튼: "아일랜드에 서버 시간 시작" / "PiP로 서버 시간 시작" / 실행 중 "시계 끄기".

## 6. Live Activity 표시 규칙

| 상태 | 레이아웃 | 시간 표기 |
|---|---|---|
| 세로 Compact | leading: 시계 아이콘 16pt / trailing: 시간 | `14:05:32` 한 줄, ":" 포함 |
| 가로 Compact (폭 제한) | 위: 시계 아이콘 → 카메라 공간 → 시·분·초 세로 쌓기 | ":" 없음. 간격 6, **시 Bold 100% / 분 Medium 85% / 초 Medium 50%** 투명도 |
| Minimal | 지름 약 37 원 | 시/분 두 줄 쌓기 13pt, 초 없음 |
| Expanded | 아이콘 + 앱 이름 / 큰 시간 44pt / 날짜 · 자동 종료까지 남은 시간 | `14:05:32` |
| 잠금 화면 (StandBy 겸용) | 앱 이름 + 시간 30pt / 오른쪽에 자동 종료까지 남은 시간 | `14:05:32` |

- 설정의 초 표시를 끄면 세로·가로 모두 초 생략.
- 12시간제는 세로에서 "오후 2:05:32" (API 검증 결과에 따라 지원 여부 결정).
- 가로 모드에서 시스템이 leading을 위, trailing을 아래로 배치하는지, 글자를 똑바로 세워 그리는지 **iOS 27 시뮬레이터에서 먼저 확인**하고 레이아웃을 맞출 것.

## 7. PiP 표시 규칙
- 배경 `#000000`, 반경 14, 아이콘 없이 시간만 가운데 정렬.
- 일반: `14:05:32` 28pt.
- 서버 시간 + 밀리초: `14:05:32.418`, 밀리초는 작게(약 2/3 크기) + 투명도 75%.
